# @gamenight/web

The Next.js 16 app: TV view, phone view and host console. See the [root README](../../README.md) to run it and the [design doc](../../docs/design.md) for how it fits together.

Next.js 16 changed several conventions (for example `middleware.ts` is now `proxy.ts`). `AGENTS.md` points coding agents at the version-matched docs bundled in `node_modules/next/dist/docs/`.
